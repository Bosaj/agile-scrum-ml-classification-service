# Academic Curriculum & Laboratory Guide 📂

This guide presents the complete educational structure, competency mapping, and lab sequence for **ENIAD Agile Scrum Delivery & Machine Learning Service**.

---

## 📑 Curriculum Matrix

| Component | Methodology | Description & Deliverables |
|---|---|---|
| `Agile Artifacts` | Scrum Management | Epics, User Stories with Acceptance Criteria, Estimation (Story Points) |
| `Sprint Execution` | Iterative Delivery | Sprint Backlog, Task Board, Burndown metrics, Definition of Done (DoD) |
| `Machine Learning` | Scikit-Learn Pipeline | Preprocessing, Feature Selection, Hyperparameter Tuning, `Agile_evulat.ipynb` |
| `Application UI` | Web Interface | Interactive input form, live model inference, probability distribution visualizations |
| `Data Management` | Ingestion & Storage | Structured dataset in `data/`, validation routines in `test/` |


---

## 🏉 Scrum Framework Implementation

- **Roles**: Product Owner (PO), Scrum Master (SM), Development Team.
- **Ceremonies**:
  1. Sprint Planning (defining Sprint Goal, committing to backlog items)
  2. Daily Standup (synchronization, impediment identification)
  3. Sprint Review (demo of working classification web service)
  4. Sprint Retrospective (continuous improvement actions)
- **Definition of Done (DoD)**:
  - Code reviewed and formatted
  - Unit and integration tests passing
  - Model cross-validation accuracy exceeding baseline threshold
  - Documentation and API endpoints validated
