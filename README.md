# 🏃 ENIAD Agile Scrum Machine Learning Delivery

Agile project lifecycle delivery combining Scrum sprints, user story backlogs, and an automated predictive machine learning web application developed for **Gestion Agile de Projet Informatique** (Semestre 7) at **ENIAD**.

---

## 🎯 Project Highlights
- **Agile Scrum Methodology**: Sprint planning, backlog grooming, velocity tracking, and sprint reviews.
- **Predictive ML Pipeline**: Trained classification pipeline (`best_classification_model.pkl`) with end-to-end evaluation metrics in `Agile_evulat.ipynb`.
- **Web Application API**: Flask / Python serving interface in `test/app.py` for real-time model inference.

## 🛠️ Stack
- **Python 3.10+**, **Flask**, **Scikit-Learn**, **Pandas**, **Jupyter**
